Personal Dashboard · Portugal

In developmentPublic

Goal: aggregate indicators on Portugal, the markets and international news on a single page, with the source and observation time of each data point.

A learning and experimentation project, under continuous development and maintenance: some sources may fail or change without notice.

  • Static application running in the browser; a Cloudflare Workers gateway proxies the sources that block direct browser requests.
  • Each card states the origin and timestamp of its data and flags it when stale.
  • Installable PWA, caching the last session for offline use.
Open the dashboard Code

What it shows

  • IPMA weather, petrol prices in Portugal and Spain, HICP and Euribor
  • Hourly OMIE electricity prices and the cheapest window of the day
  • PSI 20, exchange rates, crypto and 7, 30 and 90-day charts
  • News, earthquakes, air quality and air and sea traffic

no build step: HTML, CSS and JavaScript; CI with 6 jobs and a daily check of the live page

  • JavaScript
  • Chart.js
  • Cloudflare Workers
  • PWA

Home Server
